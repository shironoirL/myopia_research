# Исходники черновика диссертации

- `content.txt` — текст диссертации в простой разметке (редактировать здесь):
  `#U`/`#C` — структурный элемент / глава, `##`/`###` — разделы, `- ` — список,
  `> ` — комментарий для автора (жёлтый блок), `T:` — заголовок таблицы, строки `| … |` — таблица,
  `F: файл|ширина_px|высота_px|ширина_в_документе|подпись` — рисунок (из этой папки или `results/`),
  `E: формула|(номер)` — формула, `R: ` — источник в списке литературы,
  `**жирный**`, `` `код` ``, `[[TODO: …]]` — красная пометка.
- `build.js` — сборка в .docx по ГОСТ Р 7.0.11-2011 (нужен Node.js и пакет `docx`: `npm install docx`).
- `scheme.py` — рисунок 2.1 (схема пайплайна).

Сборка из этой папки:

    npm install docx
    node build.js "../Диссертация — черновой скелет.docx"
