# Датасет `myopia.csv` (OLSM) — паспорт данных

> Документ описывает основной табличный датасет Главы 1 (индивидуальный прогноз риска
> развития миопии). Все числа посчитаны напрямую из `myopia.csv`
> (`.venv/bin/python`, разделитель определяется автоматически: `sep=None`).

## 1. Происхождение и что это вообще такое

Это подвыборка **OLSM — Orinda Longitudinal Study of Myopia** (Орайнда, Калифорния),
классического продольного исследования развития детской миопии. Дети наблюдались
несколько лет; в базовый год измерялись рефракция, биометрия глаза, зрительная нагрузка
и семейный анамнез, а затем фиксировалось, **развилась ли у ребёнка миопия** за период
наблюдения.

**Критически важная деталь для всей Главы 1:**
- `MYOPIC` — это **исход**: развитие миопии в первые 5 лет наблюдения, формально
  определённое как **SPHEQ ≤ −0.75 D** на каком-либо визите наблюдения.
- Все остальные признаки (рефракция `SPHEQ`, биометрия `AL/ACD/LT/VCD`, часы нагрузки,
  анамнез) — это **baseline**, т.е. измерения **до** развития миопии.
- Проверка проспективности: на baseline **ни один** ребёнок не миоп (минимум
  `SPHEQ = −0.699`, порог −0.75 не пересечён никем). То есть таргет — честно будущий
  исход, «уже больных» в выборке нет.

Отсюда вся логика: мы прогнозируем **будущий** риск по **исходным** характеристикам
ребёнка. Это делает задачу осмысленной как модель раннего скрининга, а не как
тривиальную «диагностику уже больного».

`STUDYYEAR` в данных: **1990–1995** (год включения ребёнка в исследование).

## 2. Габариты и качество

| Характеристика | Значение |
|---|---|
| Строк (детей) | **618** |
| Колонок | **18** (1 ID + 1 служебная + 1 таргет + 15 признаков) |
| Пропусков | **0** |
| Дубликатов строк | **0** |
| Таргет | `MYOPIC` (бинарный) |
| Баланс классов | **537 (86.9%)** не-миопы / **81 (13.1%)** миопы |
| Формат | CSV; разделитель определять через `sep=None` (не запятая!) |

Дисбаланс ~1:6.6 — центральная методологическая проблема датасета. Именно поэтому в
работе акцент на **recall / FNR** (не пропустить будущего миопа), а не на accuracy,
и именно на этом строится метод SALF.

## 3. Словарь признаков

### Служебные
| Поле | Тип | Описание |
|---|---|---|
| `ID` | int | Идентификатор ребёнка (в модель **не** подаётся) |
| `STUDYYEAR` | int | Год включения (1990–1995); служебное |

### Таргет
| Поле | Тип | Описание |
|---|---|---|
| `MYOPIC` | 0/1 | **Исход:** миопия в первые 5 лет наблюдения, определяется как **SPHEQ ≤ −0.75 D**. 1 = да (81 реб.) |

### Демография
| Поле | Тип | Распределение |
|---|---|---|
| `AGE` | int | Возраст на первом визите, годы. 5:21, **6:456**, 7:82, 8:53, 9:6. Почти все — 6 лет |
| `GENDER` | 0/1 | Пол: **0 = мужской (M), 1 = женский (F)**. 0: 316, 1: 302 (сбалансирован) |

### Рефракция и биометрия глаза (baseline)
| Поле | Тип | Среднее ± SD | Смысл |
|---|---|---|---|
| `SPHEQ` | float | 0.801 ± 0.626 | **Сферический эквивалент рефракции** (эффективная оптическая сила глаза), диоптрии. Положительный = гиперметропия/норма, ближе к 0 и отрицательный = сдвиг к миопии. **Главный предиктор.** ⚠️ Тот же показатель, порогом которого (≤ −0.75 D) определён таргет → baseline-SPHEQ и `MYOPIC` связаны по построению |
| `AL` | float | 22.497 ± 0.680 | Осевая длина глаза (axial length), мм |
| `ACD` | float | 3.579 ± 0.230 | Глубина передней камеры (anterior chamber depth), мм |
| `LT` | float | 3.541 ± 0.155 | Толщина хрусталика (lens thickness), мм |
| `VCD` | float | 15.377 ± 0.664 | Глубина стекловидного тела (vitreous chamber depth), мм |

Геометрия глаза: `AL ≈ ACD + LT + VCD` (передне-задняя ось складывается из камер).

### Зрительная нагрузка (часов в неделю, baseline)
| Поле | Тип | Среднее ± SD | Смысл |
|---|---|---|---|
| `SPORTHR` | int | 11.95 ± 7.97 | Спорт / активность на улице вне школы (часы/нед) |
| `READHR` | int | 2.80 ± 3.07 | Чтение для удовольствия |
| `COMPHR` | int | 2.11 ± 3.06 | Видеоигры / работа за компьютером |
| `STUDYHR` | int | 1.49 ± 2.22 | Чтение/учёба по школьным заданиям вне школы |
| `TVHR` | int | 8.95 ± 5.72 | Телевизор |
| `DIOPTERHR` | int | 26.02 ± 16.03 | **Композит близкой нагрузки**, «диоптрио-часы». Официальная формула OLSM: **`DIOPTERHR = 3×(READHR + STUDYHR) + 2×COMPHR + TVHR`** — проверено, совпадает с данными на 100%. Вес отражает дптр-нагрузку: чтение/учёба (~3 D) весомее компьютера (~2 D) и ТВ (~1 D) |

⚠️ `DIOPTERHR` — **точная линейная комбинация** остальных полей близкой нагрузки, а не
независимый признак. Для линейных моделей это чистая мультиколлинеарность (ранговая
зависимость): либо `DIOPTERHR`, либо его компоненты — но не всё вместе.

### Семейный анамнез
| Поле | Тип | Распределение |
|---|---|---|
| `MOMMY` | 0/1 | Миопия у матери. 1: 313, 0: 305 |
| `DADMY` | 0/1 | Миопия у отца. 0: 310, 1: 308 |

## 4. Что данные говорят сами по себе (одномерный анализ)

Различия групп «стал миопом (1)» vs «нет (0)», p — Mann–Whitney U:

| Признак | non-myopic | myopic | p | Вывод |
|---|---|---|---|---|
| **SPHEQ** | 0.892 | 0.199 | **7e-26** | Резко ниже у будущих миопов. Доминирующий сигнал |
| ACD | 3.569 | 3.643 | 0.003 | Передняя камера чуть глубже у миопов |
| SPORTHR | 12.26 | 9.94 | 0.005 | Будущие миопы **меньше** занимаются спортом (защитный фактор активности) |
| AL | 22.487 | 22.563 | 0.36 | На baseline ещё **не** различается (миопия ещё не развилась!) |
| LT, VCD, READHR, COMPHR, STUDYHR, TVHR, DIOPTERHR | — | — | > 0.05 | По отдельности незначимы |

**Ключевое наблюдение:** `AL` (длина глаза) на старте не различает группы, хотя это
главный анатомический маркер уже развитой миопии. Это прямое подтверждение продольной
природы данных: мы ловим детей **до** удлинения глаза, и предсказывать приходится по
рефракционному «запасу» `SPHEQ`, а не по анатомии.

### Наследственность (сильный, но не одномерно-значимый по MWU градиент)
Доля ставших миопами в зависимости от числа близоруких родителей:

| Близоруких родителей | Доля миопов |
|---|---|
| 0 | **3.3%** |
| 1 | ~13% (мать 17.6%, отец 18.2%) |
| 2 | **22.6%** |

Чёткий дозозависимый градиент — семейный анамнез клинически важен, даже если один
предиктор слабее `SPHEQ`.

## 5. Практические заметки для моделирования

1. **Читать как** `pd.read_csv("myopia.csv", sep=None, engine="python")` — иначе колонки склеятся.
2. **Выкинуть** `ID`, `STUDYYEAR` из признаков (утечки/шум).
3. **Дисбаланс 13%** → метрики PR-AUC, recall, FNR; class_weight / пороговая настройка / SALF.
4. **Мультиколлинеарность:** `AL ≈ ACD+LT+VCD` (геометрия) и `DIOPTERHR` = точная
   линейная комбинация `READHR/STUDYHR/COMPHR/TVHR`. Для линейных моделей — не подавать
   `DIOPTERHR` вместе с его компонентами; использовать регуляризацию или отбор.
5. **Малый n (618) + 81 позитив** → простые интерпретируемые модели (LogReg) устойчивее
   тяжёлого бустинга; кросс-валидация, калибровка обязательны (см. `olsm_analysis.py`,
   `results/model_comparison.csv`).
6. **`SPHEQ` доминирует по построению.** Таргет `MYOPIC` = (будущий SPHEQ ≤ −0.75 D), а в
   признаках — baseline-SPHEQ; будущая рефракция сильно коррелирует с исходной. Это **не
   утечка** (baseline измерен до исхода), но объясняет колоссальный сигнал `SPHEQ`
   (p=7e-26) и его неизбежное доминирование. Клинически это и есть ценность: исходная
   рефракция — самый ранний дешёвый скрининговый маркер. Методически стоит показать
   модель **с** и **без** `SPHEQ`: без него видно вклад биометрии, нагрузки и анамнеза.

## 6. Ограничения (для честного раздела диссертации)

- Малый объём и сильный дисбаланс классов.
- Данные 1990-х, США, преимущественно 6-летние дети — ограниченная переносимость на
  современную российскую детскую популяцию.
- Зрительная нагрузка — самоотчёт/родительский отчёт (шум измерения).
- Кодировка `GENDER` не документирована в файле — требует сверки с первоисточником.
- Один срез baseline-признаков; динамика внутри периода наблюдения в этот CSV не входит.
