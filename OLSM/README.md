# OLSM — блок «Индивидуальный прогноз риска миопии» (Глава 1)

Самодостаточная папка: данные, код, документация и результаты по датасету `myopia.csv`.
Пройди файлы **в порядке ниже** — так тема разбирается от общего к деталям.

## Порядок изучения

### 1. `DATASET_myopia_olsm.md` — паспорт данных (читать первым)
Что за исследование OLSM, все 18 полей с медицинским смыслом, ключевые нюансы:
проспективная природа (предикторы — до развития миопии), определение исхода
`MYOPIC = SE ≤ −0.75 D`, ловушки (SPHEQ↔таргет, коллинеарность `AL≈ACD+LT+VCD` и
`DIOPTERHR`). Отсюда понятно, *с чем* мы работаем.

### 2. `olsm_chapter1_draft.md` — черновой текст главы (читать вторым)
Связный текст под ВАК: Материалы → Методы → Результаты (3 таблицы) → Обсуждение.
Здесь — *выводы*: какая модель победила, какие факторы значимы, роль SPHEQ.
Числа со ссылками на артефакты в `results/`. Требует твоей редактуры.

### 3. `olsm_analysis.py` — как всё посчитано (читать третьим)
Воспроизводимый пайплайн. Карта функций → результатов:

| Функция | Что делает | Артефакт |
|---|---|---|
| `load_data` | чтение `myopia.csv` (`sep=";"`), выброс ID/STUDYYEAR | — |
| `compare_models` | CV 5×10, 4 модели | `results/model_comparison.csv` |
| `oof_probabilities` | out-of-fold вероятности LogReg | → кривые |
| `threshold_analysis` | подбор порога скрининга | `results/threshold_analysis.csv` |
| `risk_factors` | коэф. + OOF permutation importance | `results/risk_factors.csv`, `feature_importance.png` |
| `adjusted_or` | одномерные vs скорр. OR, 95% ДИ, p (Wald) | `results/adjusted_or.csv` |
| `ablation` | вклад SPHEQ (с/без) | `results/ablation.csv` |
| `fig_roc_pr` / `fig_calibration` | графики | `roc_pr.png`, `calibration.png` |

### 4. `results/` — таблицы и графики
Открывать по ходу текста главы:
- `model_comparison.csv` — LogReg vs ансамбли (LogReg выигрывает: PR-AUC 0.59).
- `adjusted_or.csv` — таблица факторов риска (SPHEQ, спорт, наследственность).
- `ablation.csv` — только SPHEQ ≈ полная модель; без SPHEQ качество падает вдвое.
- `threshold_analysis.csv` — режимы порога (скрининг: 0.35 → recall 0.85 / spec 0.70).
- `roc_pr.png`, `calibration.png`, `feature_importance.png` — визуализация.

## Главные выводы (кратко)
- На малой несбалансированной выборке (n=618, 13% миопов) **логистическая регрессия
  устойчивее ансамблей**: ROC-AUC 0.87, PR-AUC 0.59, recall 0.79.
- **4 независимых фактора** (скорр. OR на 1 SD): исходная рефракция SPHEQ 0.078
  (доминирует, «гиперметропический резерв»), активность на улице SPORTHR 0.66
  (защитный), миопия матери 2.01 и отца 2.18.
- Один SPHEQ обеспечивает почти всё качество прогноза → ранняя рефрактометрия как
  дешёвый скрининговый маркер.

## Как перепрогнать
Из этой папки (питон — из корневого `.venv`):
```
../.venv/bin/python olsm_analysis.py
```
Скрипт прочитает локальный `myopia.csv` и перезапишет `results/` внутри этой папки.

> Примечание: это **учебная копия**. Рабочие оригиналы — в корне репозитория
> (`olsm_analysis.py`, `myopia.csv`, `article/olsm_chapter1_draft.md`, общий `results/`).
> Правки для диссертации вноси в корневые версии, чтобы не расходились.
