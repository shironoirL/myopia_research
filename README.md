# myopia_research

Код и материалы диссертации по моделированию, прогнозированию и оценке профилактики
миопии у детей.

## Запуск на новой машине

```bash
git clone https://github.com/shironoirL/myopia_research.git
cd myopia_research
poetry install
```

Мелкие датасеты лежат в репозитории. Крупные (GWAS, панель 1000 Genomes, ~8 ГБ) и PLINK
в git не входят — команды для их загрузки и описание всех источников в
[DATA_SOURCES.md](DATA_SOURCES.md). Без них не запустятся только MR-скрипты
(`clump_with_plink.py`, `mr_analysis.py`, `mr_sensitivity.py`).

## Изученные данные

### Использованы в анализе

| Датасет | Тип данных | Объём | Задача в работе | Скрипты |
|---|---|---|---|---|
| OLSM, Orinda Longitudinal Study of Myopia (США) | Проспективная когорта, индивидуальные данные | 618 детей, 18 признаков | Прогноз риска развития миопии (гл. 4), бенчмарк SALF | `olsm_analysis.py`, `salf_benchmark.py` |
| NHANES 2007–2008 (США) | Популяционное обследование со сложным дизайном | 10 149 участников в исходных файлах, в анализе 990 подростков 12–19 лет | Внешняя проверка факторов риска (гл. 4.7) | `nhanes_analysis.py`, `nhanes_survey_analysis.py` |
| Kinoshita et al., РКИ ортокератология + 0,01% атропин (Япония) | Рандомизированное исследование | 73 ребёнка, 146 глаз | Эффект вмешательства (гл. 5.1), прогноз прогрессирования SALF (гл. 3) | `ortho_analysis.py`, `salf_benchmark.py` |
| Ural Children Myopia Study, Bikbov et al. 2023 (Россия, Уфа) | Продольная когорта без лечения, 2 визита | 461 ребёнок, 922 глаза; в анализе 457 детей, 902 глаза | Внешняя проверка SALF на российских детях (гл. 3) | `salf_ural.py` |
| GWAS: окончание колледжа (Loh et al. 2018, UK Biobank) | Сводные статистики GWAS | 454 813 человек | Экспозиция в MR (гл. 5.2) | `mr_analysis.py` |
| GWAS: миопия (Jiang et al. 2021, UK Biobank) | Сводные статистики GWAS | 36 623 случая, 419 031 контроль | Исход в MR (гл. 5.2) | `mr_analysis.py` |
| 1000 Genomes Phase 3, европейская подвыборка | Референсная панель генотипов | 503 человека | LD-клампинг инструментов MR | `clump_with_plink.py` |

### Просмотрены, но в анализ не вошли

| Датасет | Объём | Почему не используется |
|---|---|---|
| Обзоры по образу жизни (`datasets/Physical activity…/`) | 5 обзоров (PDF) | Не данные, а литература для главы 1 |
| Kaggle Myopia Image Dataset, Myopia images | Только ссылки | Изображения глазного дна — другая задача (компьютерное зрение), вне рамок работы |
| Zenodo, дети в очках DIMS ([18166476](https://zenodo.org/records/18166476)) | 20 детей, 36 мес. | Слишком малая выборка, не российские данные |
| Ural Children Eye Study (Уфа, BJO 2024) | 4 933 ребёнка | Не открыт, данные по запросу авторам; кандидат для внешней проверки факторов риска (гл. 4) |

### Итого

- **Индивидуальные данные:** 2 138 детей и подростков в анализе из четырёх независимых источников: 618 (OLSM) + 990 (NHANES) + 73 (Kinoshita) + 457 (Ural). Три страны: США (OLSM, NHANES), Япония (Kinoshita), Россия (Ural).
- **Генетические данные:** сводные статистики GWAS примерно по 455 тыс. участников UK Biobank (экспозиция и исход из одной когорты) и референсная панель из 503 европейцев.
- **Российские данные:** Ural Children Myopia Study — единственный найденный открытый набор индивидуальных данных по миопии у российских детей (поиск по Zenodo, figshare, Mendeley Data, PLOS и русскоязычным источникам, октябрь 2026).
