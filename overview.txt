Тема работы
===========

Рабочая формулировка:

    Математическое моделирование, прогнозирование развития и оценка эффективности
    профилактики миопии среди детского населения на основе информационных технологий.

Главная идея:

    Не строить одну "самую точную модель" на одном датасете, а собрать
    воспроизводимый информационно-аналитический пайплайн:

    1. прогноз индивидуального риска развития миопии;
    2. интерпретация факторов риска;
    3. внешняя проверка факторов на популяционных данных;
    4. оценка контроля прогрессирования/вмешательства;
    5. сценарная оценка профилактических факторов;
    6. причинно-ориентированная проверка части факторов через Mendelian randomization.

1. OLSM / myopia.csv
--------------------

Основной табличный датасет для первой ML-части.

Размер:

    618 строк
    18 колонок

Целевая переменная:

    MYOPIC

Баланс классов:

    MYOPIC = 0: около 87%
    MYOPIC = 1: около 13%

Признаки:

    AGE, GENDER
    SPHEQ
    AL, ACD, LT, VCD
    SPORTHR, READHR, COMPHR, STUDYHR, TVHR, DIOPTERHR
    MOMMY, DADMY

Роль в работе:

    Основной датасет для прогноза риска развития миопии и сравнения ML-моделей.

Особенность:

    Файл разделен точкой с запятой, поэтому читать нужно через sep=None
    или sep=";".

Ограничение:

    но не заменяет продольное наблюдение развития миопии.

Созданные notebook-файлы
========================

1. sss.ipynb
------------

Основной notebook по OLSM / myopia.csv.

Содержит:

    - загрузку локального myopia.csv;
    - корректное чтение semicolon-separated CSV;
    - EDA;
    - словарь признаков;
    - визуализацию;
    - baseline Logistic Regression;
    - гибридную модель:

          Logistic Regression + GradientBoostingRegressor по остаткам

      Формула:

          residual = y_true - p_linear
          p_hybrid = clip(p_linear + alpha * residual_correction, 0, 1)

    - подбор alpha через cross-validation;
    - сравнение:

          Logistic Regression
          Gradient Boosting Classifier
          Hybrid Residual Model

    - метрики:

          ROC-AUC
          PR-AUC
          recall
          specificity
          F1
          false_negative_rate
          TP / FP / TN / FN

Результат на текущем split:

    Best alpha by CV PR-AUC: 0.4

    Logistic Regression:
        PR-AUC = 0.468
        recall = 0.55
        FNR    = 0.45

    Hybrid alpha=0.4:
        PR-AUC = 0.456
        recall = 0.40
        FNR    = 0.60

Вывод:

    Гибридная схема на текущем split не улучшила чувствительность и FNR.
    Это не провал, а нормальный научный результат: на малом несбалансированном
    медицинском датасете простая интерпретируемая модель может быть устойчивее.

Mendelian randomization
=======================

Идея:

    Добавить отдельный causal-блок через двухвыборочную менделевскую
    рандомизацию на открытых GWAS summary statistics.

Важно:

    MR напрямую не применяется к текущим CSV, потому что там нет генотипов.
    Нужны GWAS summary statistics:

        SNP -> exposure
        SNP -> outcome

Потенциальные вопросы:

    education -> myopia / refractive error
    time outdoors -> myopia
    screen time / computer use -> myopia
    sleep duration -> myopia
    physical activity -> myopia
    sedentary behaviour -> myopia
    vitamin D -> myopia
    BMI -> myopia

Источники GWAS:

    OpenGWAS
    GWAS Catalog
    FinnGen

Потенциальный outcome:

    FinnGen myopia:
        finngen_R9_H7_MYOPIA

Потенциальные exposures:

    educational attainment
    time spent outdoors
    time spent using computer
    sleep duration
    physical activity
    sedentary behaviour
    vitamin D
    BMI

Роль MR в диссертации:

    Не главный метод, а дополнительная причинно-ориентированная проверка:

        ML-модели показывают ассоциации и прогнозируют риск.
        MR помогает проверить, есть ли причинная поддержка у части
        профилактических факторов.

Ограничения MR:

    - GWAS часто взрослые, а тема про детей;
    - lifestyle traits могут иметь слабые genetic instruments;
    - возможна pleiotropy;
    - нужно проверять heterogeneity;
    - MR работает на уровне популяции, а не индивидуального ребенка;
    - MR не равен прямой оценке конкретной профилактической программы.

Возможная формулировка вклада
=============================

    Разработана воспроизводимая информационно-аналитическая методика
    для стратификации риска и поддержки профилактики миопии у детей
    с использованием открытых медицинских данных, машинного обучения,
    интерпретируемого анализа факторов риска и причинно-ориентированной

Сильные стороны работы
======================

    - не один Kaggle-классификатор;
    - несколько открытых источников данных;
    - ML + медицинская интерпретация;
    - акцент на recall/FNR, а не только accuracy;
    - есть блок эффективности вмешательства;
    - можно добавить causal-блок через MR;
    - можно показать расширение на computer vision.


Риски и ограничения
===================

Нужно честно описать:

    - малый размер OLSM;
    - дисбаланс классов;
    - не все данные longitudinal;
    - не все данные детские;
    - нет единого датасета, где есть все признаки, вмешательства и исходы;
    - MR часто основана на adult GWAS;
    - MR не дает индивидуальный прогноз;
    - переносимость моделей между популяциями ограничена;
    - сложные модели не обязательно лучше логистической регрессии на малых данных.
